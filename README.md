# rawi-assets

Visuels publics de la chaîne YouTube **الراوي / Rawi Zone** : miniatures et images d'épisodes.

Structure : `<série>/<numéro>/thumb.jpg` (+ images d'épisode si besoin)
- `trend/` — ترند
- `malafat/` — ملفات
- `idhaat/` — إذاعة الغد

Les fichiers sont servis via `https://raw.githubusercontent.com/meralae0/rawi-assets/main/<chemin>`.
