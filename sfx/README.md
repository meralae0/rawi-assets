# Bibliothèque de bruitages — الراوي
Sons réels, licence **CC0 1.0** (Freesound), nettoyés : début de silence coupé, durée limitée, fondu de sortie, pic à −1 dBFS, WAV 48 kHz stéréo. Liste, durées et sources exactes : `index.json`.

Catégories :
- **transition** : whoosh_soft, whoosh_light, whoosh_quick, swoosh_long, whoosh_glitch, swirl
- **impact** : boom_cinematic, riser_slam_boom, boom_short, boom_charang, impact_thud
- **tension** : riser_long, riser_short, riser_uneasy, drone_low (lit de suspense), heartbeat_loop, heartbeat_kick, clock_tick
- **graphic** : glitch, stamp, shutter, typewriter_key, typewriter_bell, typewriter_slide, paper_shake, page_flip, page_turn, paper_rip

Usage : discret (−10 à −16 dB sous la voix), seulement sur animations graphiques, révélations et changements de chapitre ; jamais sur chaque coupe. `tools/agfx.py` → `sfx_track()` les mixe automatiquement.
